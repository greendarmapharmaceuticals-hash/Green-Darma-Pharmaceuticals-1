# Green Darma Pharmaceuticals
## Antigravity IDE Master Prompt

Build a production-ready Pharmaceutical Product Marketing Website using:

- Laravel 12
- PHP 8.3+
- MySQL 8+
- Blade
- Bootstrap 5
- JavaScript

## Core Requirements
- Modern medical UI
- Mobile-first responsive design
- Fast loading
- SEO optimized
- Secure coding
- Clean architecture

## Website Pages
- Home
- About
- Products
- Product Details
- Contact
- Privacy Policy
- Terms
- 404

## Product System
Create dynamic CRUD:
- Add
- Edit
- Delete
- Duplicate
- Preview
- Publish
- Draft

Fields:
- Name
- Generic Name
- Category
- Strength
- Pack Size
- Price
- Description
- Indications
- Dosage
- Side Effects
- Storage
- Featured Image
- Gallery
- SEO Fields

## Admin Panel
Design for beginners.
Use large buttons, step-by-step forms, drag & drop image upload, clear icons, simple navigation.

## SEO
Generate:
- Unique slug
- Meta title
- Meta description
- Keywords
- JSON-LD Product Schema
- FAQ Schema
- Breadcrumb
- Sitemap
- robots.txt

## Performance
- Lazy Loading
- WebP Images
- Image Compression
- Caching
- Optimized Queries

## Security
- CSRF
- Validation
- Authentication
- Password Hashing
- Secure Upload

## Code Quality
Follow PSR-12.
Keep controllers thin.
Use services where appropriate.
Write reusable Blade components.

## Deployment
Project must be production-ready for Hostinger/VPS deployment.

Generate clean, maintainable and scalable code.
