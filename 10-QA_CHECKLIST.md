# 10-QA_CHECKLIST.md

# Green Darma Pharmaceuticals

## Quality Assurance Checklist

### Purpose
Ensure every feature is tested before deployment.

## Backend
- All migrations run successfully
- Seeders work correctly
- CRUD operations tested
- Validation rules verified
- Authentication tested
- Authorization tested
- No server errors

## Frontend
- Homepage loads correctly
- Product pages display correctly
- Search works
- Contact form works
- Responsive on mobile, tablet and desktop
- Cross-browser compatibility checked

## Admin Panel
- Login
- Logout
- Add Product
- Edit Product
- Delete Product
- Upload Images
- Replace Images
- Update Company Settings
- Update SEO Settings

## SEO
- Meta titles
- Meta descriptions
- Canonical URLs
- Sitemap.xml
- robots.txt
- JSON-LD Schema
- Breadcrumb Schema
- ALT text for images

## Performance
- Lazy loading enabled
- WebP images
- Optimized assets
- Caching enabled
- Core Web Vitals checked

## Security
- CSRF protection
- XSS prevention
- SQL injection prevention
- File upload validation
- Password hashing

## Accessibility
- Keyboard navigation
- Readable fonts
- Color contrast
- Image alt text

## Deployment
- .env configured
- Storage linked
- Cache cleared
- Config cached
- Routes cached
- Production mode enabled

## Git Checklist
- Commit complete
- Meaningful commit message
- Push to GitHub
- No secrets committed

## Final Approval
Project is production-ready only when every checklist item passes.
